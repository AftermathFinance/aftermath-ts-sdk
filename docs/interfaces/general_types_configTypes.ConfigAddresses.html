    Interface ConfigAddresses

    Network-specific package and object addresses used by Aftermath providers.

    Each section is optional. Pass addresses for the same network as the configured Sui client to Aftermath.create({ addresses }) to skip address discovery. A provider that requires an omitted section throws when it is created.
