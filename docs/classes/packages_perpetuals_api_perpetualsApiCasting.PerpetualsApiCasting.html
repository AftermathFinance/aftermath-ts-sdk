    Class PerpetualsApiCasting

    Converts raw Sui perpetuals events into the SDK's camel-case event types.

    These static helpers do not perform network I/O. They convert bigint-like strings and fixed-point strings from parsedJson, preserve the event timestamp in milliseconds, and copy the transaction digest and event type.
